# Arsip rancangan dan implementasi

Folder [plans](plans/) dan [specs](specs/) menyimpan riwayat keputusan serta rencana pekerjaan proyek sebelumnya. Dokumen bertanggal bukan instruksi untuk menjalankan atau melanjutkan pekerjaan secara otomatis.

Lokasi file dipertahankan agar tautan lama tetap berlaku. Panduan template yang aktif tersedia di [indeks dokumentasi](../README.md); riwayat lainnya ada di [indeks arsip](../archive/README.md).
